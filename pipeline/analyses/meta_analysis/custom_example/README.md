# custom_example: example consortium meta-analysis method

A minimal example to copy when contributing a meta-analysis method (see `CONTRIBUTING.md`).

| Method | What it does |
|---|---|
| `custom_example/custom_meta_analysis` | Sample-size weighted Z-score meta-analysis (Stouffer): combines each dataset's Z = BETA/SE, weighted by √N or equally. Useful when effect sizes aren't on comparable scales |
